# 魔方计时器 · 手机版（iPhone / Safari）

对着电脑没有键盘的场景做的触屏版：**按住屏幕准备、松手开始、再按一下结束**。
浅色玻璃拟态界面（**无夜间模式**），成绩保存在手机本地，离线可用。

效果图见 `screenshots/`（390×844，iPhone 竖屏 1:1）。

---

## 一、在 iPhone 上怎么用

这不是 App Store 里的安装包，而是**网页应用（PWA）**。装到主屏后，用法和真 App 一样：

1. 电脑上启动服务：在本文件夹运行 `node serve.js`
   （启动后会打印一个 `http://172.x.x.x:8099/` 的手机访问地址）
2. **iPhone 与电脑连同一个 Wi-Fi**
3. iPhone 用 **Safari** 打开那个地址（注意：必须是 Safari，微信内置浏览器不能装主屏）
4. 点底部中间的 **分享** 按钮 → **添加到主屏幕** → 命名「魔方计时」→ 添加
5. 之后从主屏图标打开：全屏、无地址栏、有自己的图标、**断网也能用**

> 想完全脱离电脑：也可以用「文件」App 把 `index.html`、`stats.js` 传到 iPhone 上，
> 直接双击用 Safari 打开。缺点是每次都要点文件、不能装主屏、且不能离线缓存。

## 二、操作方式

| 动作 | 结果 |
| --- | --- |
| **按住屏幕** | 计时卡片变绿，进入「准备」状态（约 0.3 秒，防手滑） |
| **松开手指** | 立即开始计时 |
| **再按一下屏幕** | 停止并记录成绩（屏幕任意位置都行，不用瞄准） |
| 侧边「DNF」 | 把选中的成绩标为 DNF；没选中时标记最新一条 |
| 侧边「删除本次」 | 删除最新一条成绩（你要的删除功能） |
| 侧边「删除选中」 | 删除列表中点选的成绩（可多选） |
| 侧边「撤销」 | 撤销删除 / DNF 标记（最多 8 步） |
| 侧边「导出」 | 导出 CSV（iOS 会弹出存储/分享面板） |
| 点列表某行 | 选中/取消选中；上下拖动可滚动 |

计时时手机不会自动锁屏（用 Screen Wake Lock，iOS 16.4+ 支持）；
准备与停止时有轻微触感反馈（iOS 不支持 `navigator.vibrate`，所以不会震动，属正常）。

## 三、统计口径（与电脑版一致）

最好成绩、平均成绩、mo3、ao5、ao12、ao50、ao100。
平均遵循 WCA 规则：**去掉最好与最差各一次**后取算术平均；
样本不足显示 `—`，被计入的部分含 DNF 则显示 `DNF`。

## 四、文件说明

| 文件 | 作用 |
| --- | --- |
| `index.html` | App 本体（界面 + 触摸逻辑），**核心文件** |
| `stats.js` | 统计核心（纯函数，浏览器与 Node 测试共用） |
| `manifest.webmanifest` | PWA 配置（名称、图标、全屏模式） |
| `sw.js` | 离线缓存（装到主屏后断网可用） |
| `icon-180.png` / `icon-512.png` | 主屏图标 |
| `serve.js` | 极简静态服务器（给手机访问用，零依赖） |
| `tests/` | 自测：`stats.test.js` 统计逻辑、`page.check.js` 页面一致性 |
| `tools/` | 开发用：生成图标、拉截图、触摸流程验收 |
| `screenshots/` | 效果图 |

成绩存在手机的 `localStorage` 里（键名 `cubeTimerMobile.v1`），
清除 Safari 网站数据会一并清掉，重要成绩建议用「导出」备份。

## 六、使用限制（重要）

**软件本身没有限制**：不收费、不需登录、不计次数、没有试用期，就是一份网页代码。

真正需要知道的是下面这些「结构上的限制」：

### 1. 只能装一次，之后可以脱离电脑

添加到主屏并在联网状态下打开过一次后，程序会被缓存到手机上；
**之后电脑关机、页面关闭都不影响使用**（本来就是纯本地运行，不联网、不上传任何数据）。

但如果从主屏点开提示「无法连接」或白屏，说明缓存没建立成功——第一次打开必须是
电脑开着、同一个 Wi-Fi、Safari 里打开成功一次。

### 2. 成绩存在手机本地

存在 Safari 的 `localStorage` 里。**清除 Safari 数据 / 网站数据会一起清掉**，
iOS 也可能自动清理长期不用的网站数据。重要成绩请用「导出」存一份 CSV。

### 3. 各平台能力差异

| 能力 | iPhone | 安卓 |
| --- | --- | --- |
| 加到主屏当应用 | 支持 | 支持（还能在 Chrome 里「安装应用」） |
| 离线使用 | 支持 | 支持 |
| 计时中不锁屏 | 需 iOS 16.4+ | 支持 |
| 停止时震动反馈 | 不支持（`navigator.vibrate` 被禁用） | 支持 |
| 导出 CSV | 走 iOS 分享/存储面板 | 直接下载到「下载」文件夹 |

### 4. 安卓手机怎么用

同一份代码直接能用，两种方式：

- **同一个 Wi-Fi**：电脑上跑 `node serve.js`，安卓用 **Chrome** 打开打印出来的
  `http://172.x.x.x:8099/` → 菜单 → **安装应用 / 添加到主屏幕**。
- **完全脱离电脑**：把 `index.html` 与 `stats.js` 传到安卓手机（微信/QQ/数据线/AirDrop 均可），
  用 Chrome 打开 `index.html` 即可，成绩同样保存在本机。

### 5. 多设备成绩不互通

程序不联网，所以 iPhone 和电脑上的成绩是两个独立列表，不会同步。

## 七、自测（电脑上）

```bash
node tests/stats.test.js     # 统计逻辑：11 项全通过
node tests/page.check.js     # 页面一致性：id/API/交互绑定检查
node tools/phone-shots.js    # 生成 390x844 效果图（需先启动 serve.js）
```

`tools/touch-check.js` 会用无头浏览器模拟「按住→松开→再按」三种场景并截图，
但无头浏览器的虚拟时间不驱动动画帧，这部分结论以真机为准。

## 八、其它说明

- 想要真正的 `.ipa` / `.apk` 安装包或上架应用商店，必须在 **macOS + Xcode**（iOS）
  或 Android Studio（安卓）里重新实现一遍，Windows 上没有可下载的工具能绕开这一点。
- 网页版没有任何运行环境依赖：不需要装 Python、Node、任何 App，浏览器就是运行时。
